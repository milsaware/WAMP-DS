# Development Entry #05 - Ctrl+D Line and Selection Duplication

**Date:** 17 August 2026  
**Area:** Code Editor / Developer Experience  
**Type:** Feature / Enhancement  
**Status:** Complete

---

## The Feature

With Find and Replace now integrated into the Code Editor, another small editor improvement became obvious during normal development.

Duplicating code is something developers do constantly.

Whether creating another HTML element, copying a CSS rule, duplicating a function call or simply repeating a line while experimenting, having to manually select, copy and paste code adds unnecessary friction.

The desired behaviour was simple:

- `Ctrl+D` should duplicate the current line
- If text is selected, only the selected content should be duplicated
- The duplicated content should remain immediately available for further editing
- The operation should work entirely from the keyboard

The intention was to make duplication feel like a natural part of the WAMP-DS editor rather than something that required the clipboard.

---

## The Existing Editor

WAMP-DS uses AvalonEdit as the underlying editor control.

The editor already provides access to:

- The current caret position
- The current selection
- The document
- Individual document lines
- Direct document insertion and replacement

This meant that the duplication functionality could be implemented directly inside `CodeEditor`.

There was no need for a separate command system or additional editor component.

The operation could simply determine what the developer was currently working with and duplicate it appropriately.

---

## Keyboard Shortcut

The first part of the implementation was adding `Ctrl+D` to the existing editor keyboard handling.

The Code Editor already handled `Ctrl+F`, `Ctrl+H` and `Escape`.

The new shortcut was added alongside them:

```csharp
if (
    e.Key == Key.D &&
    Keyboard.Modifiers == ModifierKeys.Control
)
{
    DuplicateCurrentLine();

    e.Handled = true;

    return;
}
```

This keeps the shortcut handling together in the Code Editor rather than distributing editor commands throughout the application.

The resulting shortcuts are now:

    Ctrl + F
        ↓
    Find

    Ctrl + H
        ↓
    Replace

    Ctrl + D
        ↓
    Duplicate

---

## Duplicating a Line

When there is no active selection, `Ctrl+D` duplicates the line containing the caret.

The current caret position is used to identify the corresponding AvalonEdit document line:

```csharp
int offset = EditorTextBox.CaretOffset;

var document = EditorTextBox.Document;

var line = document.GetLineByOffset(offset);
```

The contents of that line can then be retrieved directly from the document:

```csharp
string lineText = document.GetText(
  line.Offset,
  line.Length
);
```

The duplicated line is inserted immediately after the original.

The implementation also takes the document's newline format into account rather than assuming that every document uses the same line ending.

This means the duplication operation works naturally with the document being edited.

---

## Selection-Aware Duplication

The behaviour became more useful when considering text selection.

If the developer has selected some text, duplicating the entire line would not necessarily be what they intended.

For example, given:

```html
<h1>Hello world</h1>
```

if only:

```text
Hello world
```

is selected, `Ctrl+D` should duplicate **Hello world**, not the entire `<h1>` element.

The implementation therefore checks for an active selection before falling back to line duplication:

```csharp
if (EditorTextBox.SelectionLength > 0)
{
    int selectionStart = EditorTextBox.SelectionStart;

    int selectionLength = EditorTextBox.SelectionLength;

    string selectedText = EditorTextBox.SelectedText;

    if (string.IsNullOrEmpty(selectedText))
        return;
```
The selected content can then be inserted immediately after the original selection:

```csharp
EditorTextBox.Document.Insert(
    selectionStart + selectionLength,
    selectedText
);
```

The newly duplicated content is then selected so that it is immediately available for further editing.

This creates a useful distinction:

    No Selection
        ↓
    Duplicate Current Line

    Text Selected
        ↓
    Duplicate Selected Content

---

## Why Selection Handling Matters

This small distinction makes the shortcut considerably more useful.

For example, with:

```html
<div class="container">
    <h1>Hello world</h1>
</div>
```

selecting:

```text
Hello world
```

and pressing `Ctrl+D` duplicates only the selected content.

The editor therefore becomes responsive to what the developer is actually trying to manipulate rather than blindly duplicating the entire line.

This is a small interaction, but it is the sort of detail that makes an editor feel more natural.

---

## Keeping the Operation Inside the Editor

No clipboard operation is required.

The duplication happens directly against the AvalonEdit document:

```csharp
EditorTextBox.Document.Insert(
    selectionStart + selectionLength,
    selectedText
);
```

For line duplication, the same document is modified directly.

This keeps the operation self-contained within WAMP-DS.

The developer does not need to:

1. Select the text
2. Copy it
3. Move the caret
4. Paste it
5. Reposition the selection

Instead:

    Ctrl+D

performs the operation directly.

---

## Integration With Existing Editor Behaviour

The new duplication functionality was added without changing the existing Find and Replace functionality.

The Code Editor now handles several common keyboard-driven operations in one place:

    Ctrl + F
        Find

    Ctrl + H
        Replace

    Ctrl + D
        Duplicate

    Enter
        Find / Replace

    Escape
        Close Find / Replace

This keeps the editor's interaction model consistent.

The features are also independent of one another, meaning adding duplication did not require changes to the search implementation.

---

## Verification

The duplication feature was tested through normal editor use.

With the caret positioned inside a line:

```text
<h1>Hello world</h1>
```

pressing:

```text
Ctrl+D
```

produces:

```text
<h1>Hello world</h1>
<h1>Hello world</h1>
```

Text selection was then tested separately.

When part of a line is selected, only the selected content is duplicated rather than the entire line.

The shortcut also works without requiring the mouse or clipboard.

The resulting workflow is:

    Position Caret
        ↓
    Ctrl + D
        ↓
    Current Line Duplicated

or:

    Select Text
        ↓
    Ctrl + D
        ↓
    Selected Content Duplicated

---

## Result

What initially looked like a very small editor shortcut became another useful improvement to the WAMP-DS development experience.

The implementation required the editor to distinguish between two different intentions:

- duplicating a complete line
- duplicating specifically selected content

That distinction makes the shortcut considerably more useful than simply copying the current line every time.

The final behaviour is:

**No selection:** `Ctrl+D` duplicates the current line.

**Selection:** `Ctrl+D` duplicates only the selected content.

The operation happens directly inside the AvalonEdit document, without requiring clipboard interaction.

This is another example of how using WAMP-DS for actual development is influencing its design.

The feature wasn't added because a specification demanded a duplication command.

It was added because while working inside the editor, the thought occurred:

> "I want to duplicate this."

And now:

```text
Ctrl + D
```

does exactly that.

The editor is becoming less about simply providing the tools required to write code and more about removing the little pieces of friction that get in the way of actually writing it.

That's the difference between an editor that **works** and an editor that starts to **feel right**.
